Comment executer ce rapport

Cette interface genere une requete SQL sur la base PBX du 3CX (PostgreSQL). Une fois connecte, cliquez sur Executer le rapport : la requete est envoyee directement a la base PostgreSQL via l'API protegee (/api/cdr/query) et les resultats s'affichent ici.
